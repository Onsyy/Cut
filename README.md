# Cut — calorie tracker

Free, installable calorie tracker with barcode scanning (Open Food Facts).
Data is saved in your browser on each device.

## Put it online (GitHub Pages, free)

Go to **Settings → Pages**. Under "Branch", pick `main` and `/ (root)`, then **Save**.
After a minute or two your app is live at `https://YOUR-USERNAME.github.io/cut/`.

## Install on your phone

- **iPhone:** open the link in Safari → Share → **Add to Home Screen**.
- **Android:** open the link in Chrome → ⋮ → **Install app**.

The camera only works over https, which GitHub Pages gives you automatically.

## Updating

Upload the changed files to the repository again. The app picks up the new
version the next time it's opened with internet.
